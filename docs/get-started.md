# Get Started

このサイトは、**namiyamaという人物を一つのソフトウェアに見立てたドキュメント**です。VitePressで構築していますが、実際にインストールできるライブラリやAPIを公開しているわけではありません。

いわゆるポートフォリオを作ろうとしたというより、「自分自身をライブラリのようにドキュメント化したら面白そうだ」と思ったことが制作のきっかけです。

## Quick Start

このドキュメントの入口は次のとおりです。

1. [Overview](/about) — 基本情報、現在の関心、技術スタック。
2. [Development](/development) — プログラミングを始めた経緯と開発スタイル。
3. [Activities](/activities) — 学業、団体活動、インターン、会社経営。
4. [Projects](/works) — 制作したサービス、ツール、Bot。
5. [Open Source](/oss) — OSSへのPull Requestと、その背景。

## このドキュメントの読み方

開発したものだけでなく、**何を考えて始めたのか、実際にはどこまでやったのか**も記載しています。所属したことと成果を出したこと、制作したことと実際に使われていることは分けています。

内容は本人へのインタビューと公開できる活動記録に基づいています。公開情報として不適切な内部事情や、確認していない成果は含めません。
