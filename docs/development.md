# Development

## 初期バージョン：AIと掲示板

中学2年生の頃、ChatGPTなどのAIがプログラミングできると知り、コードを生成してもらうところから開発を始めました。

最初に作ったものの一つは、Google Apps ScriptのHTML公開機能を使った掲示板です。当時はサーバーとクライアントの違いもよく分かっておらず、投稿データをローカルストレージに保存していたため、利用者同士で投稿を共有する掲示板にはなっていませんでした。

この経験から基礎を勉強する必要性を感じましたが、すぐに本格的な学習に取り組んだわけではありません。

## 基礎の学習：ZEN Study

中学3年生のとき、N高グループへの早期出願特典でZEN Studyの教材を利用できるようになり、「Webアプリケーション開発」を11月から翌年3月にかけて学習しました。

| 教材                     | 主に取り組んだこと                                                        |
| ------------------------ | ------------------------------------------------------------------------- |
| Webアプリケーション開発1 | HTML、CSS、GitHub Pagesによる静的サイト公開                               |
| Webアプリケーション開発2 | Linux、Git、Docker、Node.js、非同期処理、Slack Bot                        |
| Webアプリケーション開発3 | HTTP、デプロイ、Cookie、認証、データベース、基本的なセキュリティ          |
| Webアプリケーション開発4 | Webフレームワーク、GitHub Apps、CI/CD、データモデリング、予定調整サービス |

教材に沿って学びながら、小さなWebアプリも自主制作していました。ReactやNext.jsなどを扱う付録もありましたが、当時はそこまで深く取り組んでいません。

## 作りたかったもの：Anzdrop

プログラミングに詳しくなる前から、Fileforceやギガファイル便のようなファイル転送サービスの仕組みに興味がありました。

「暗号化や使い勝手を工夫すれば、自分でも使いたくなるサービスを作れるのではないか」と考えたのがAnzdropの出発点です。既存サービスより高い安全性を実証したという意味ではなく、**作ってみたいと思った理由**です。

## チャット型AIからコーディングエージェントへ

当初は無料プランのチャット型AIにコードを書いてもらい、その回答をコピー＆ペーストしていました。作業は煩雑で、会話が長くなると文脈が失われたり、方針が繰り返し変わったりすることもありました。

その後、Claude CodeやCodexなどのコーディングエージェントを使えるようになり、以前は半月ほどかかっていた作業が10分程度で済むこともありました。これは特定の作業における自身の体感であり、一般的な性能比較ではありません。

## 現在のワークフロー

TypeScript、Hono、Next.js、Astroをよく使います。

企画・技術選定・設計は厳密な手順に固定せず、まず実装しながら考えることもあります。一方、動作検証では自分でブラウザを操作して、想定したとおりに動くかを確認しています。

OSSへの貢献については、PRの数そのものを増やすより、利用者やメンテナーにとって意味のある変更を提出したいと考えています。詳しくは[Open Source](/oss)を参照してください。
