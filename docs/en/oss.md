# Open Source

I started contributing to open source because I liked the idea of code I wrote becoming part of software that many people use.

At the same time, every pull request creates review and maintenance work for other people. Rather than submitting PRs just to increase a number, I want to focus on changes that fix real problems or improve usability.

## Contribution Policy

Even a small change can be valuable if it solves a real problem. I prefer that over cosmetic changes made only to build a contribution record.

I also try to be mindful of the time maintainers spend reviewing contributions.
