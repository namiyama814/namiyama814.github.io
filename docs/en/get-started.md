# Get Started

This is **documentation for namiyama, presented as if a person were a software project**. The site is built with VitePress, but it is not an installable library or an actual API.

It began with a simple idea: *Wouldn't it be interesting to document myself like a library?* It is a personal site, but it borrows the structure of technical documentation rather than a conventional portfolio.

## How to read this documentation

The goal is not just to list projects, but to explain **why I started them and what I actually did**. Being a member of an organization is different from delivering a project; building a tool is different from having an active user base.

The content comes from interviews and activities I can describe publicly. Unverified achievements and private matters involving other people are intentionally left out.
